# messagevisor-example-cloudflare-pages

This example models `dev`, `staging`, and `production` as independent
Messagevisor sets, while using Cloudflare Pages to serve the datafiles.

Learn more at [https://messagevisor.com](https://messagevisor.com).

Example datafile URL: https://messagevisor-example-cloudflare-pages.pages.dev/production/messagevisor-web-en-US.json
